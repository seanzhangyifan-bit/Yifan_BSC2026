crack_stats: method schematic + real examples

Two independent halves. The schematic cases run known-ground-truth synthetic patterns through the exact binarize → skeletonize → graph-extract chain export_crack_stats.py uses, and check the measured numbers against hand-computable exact answers — this is the proof that the pipeline measures what it claims to measure, fully reproducible from examples/generate_examples.py with no external data. The real cases show the same pipeline on actual micrographs from this project's private raw dataset (not bundled in this export — see README.md); the numbers shown are the pipeline's actual output on real data, included for illustration, not independently re-verifiable without that dataset.
